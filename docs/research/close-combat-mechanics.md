# Close Combat 机制调研

> 目的：弄清 Close Combat（下称 CC）系列到底"好玩在哪"，为 Close Fight 的设计提供参照。
> 我们做的是**同类型的原创游戏**：借鉴玩法思路，不复用 CC 的名字、美术、地图、音效和关卡。
>
> 资料等级：✅ = 读过原文（维基百科 / CC1 官方说明书）；🔶 = 来自评测、论坛或其他作品的说明书；💭 = 我的记忆，待核实。

## 1. 系列概览 ✅

| 年份 | 作品 | 开发 / 发行 | 背景 | 要点 |
|---|---|---|---|---|
| 1996 | Close Combat | Atomic Games / Microsoft | 诺曼底后，美 29 师 vs 德 352 师，向圣洛推进 | 开山作，实时、俯视 2D；线性战役，43 天内拿下圣洛 |
| 1997 | CC II: A Bridge Too Far | Atomic / Microsoft | 市场花园行动 | 战役按"行动(Operation)"组织，可以停火休整 🔶 |
| 1998/99 | CC III: The Russian Front | Atomic / Microsoft | 东线 1941–45，**含斯大林格勒** | 大战役从巴巴罗萨打到柏林，双方可选，同一批士兵贯穿全程；有征用点数（Requisition） |
| 1999 | CC IV: Battle of the Bulge | Atomic / SSI | 阿登反击战 | **引入战略地图**：40 多个区域，"战斗群"在区域间移动，有补给线 🔶 |
| 2000 | CC V: Invasion Normandy | Atomic / SSI 或 Mattel（来源有分歧） | 诺曼底登陆 | 延续战略地图 |
| 2004–05 | Marines / Road to Baghdad / First to Fight | Atomic 等 | 现代战争 | 军用训练版，以及唯一的第一人称射击作品 |
| 2007 | Cross of Iron | CSO Simtek / Matrix | CC3 重制 | 新单位与地图，改进编辑器 |
| 2008–10 | Wacht am Rhein / The Longest Day / Last Stand Arnhem | Matrix | CC4 / CC5 / CC2 的重制 | Last Stand Arnhem 改动最大 |
| 2012 | Panthers in the Fog | Matrix / Slitherine | 吕蒂希行动 | 首个 32 位色版本 |
| 2014 | Gateway to Caen | Matrix | 埃普索姆行动 | 首个上 Steam 的作品 |
| 2019 | The Bloody First | Matrix / Slitherine | 突尼斯 → 西西里 → 诺曼底 | **首个 3D 作品**（新引擎） |

- 系列总销量：到 2018 年超过 500 万份（前五作约 120 万）。
- 2019 年后没有查到新作。我们没找到任何 2025–2026 年的新作公告，和"再也没更新过"的印象一致。
- 2007 年之后的作品大多是旧作重制，核心玩法二十多年基本没变。

## 2. 一场战斗的流程 ✅

```
选择兵力 ─▶ 部署阶段 ─▶ 实时战斗（可暂停） ─▶ 战斗结束 ─▶ 战后结算（伤亡 / 经验 / 勋章）─▶ 下一场
```

- **规模**：排到连级。每方大约十几个"小组"（Team），每个小组 2–12 人，每个士兵**有名有姓**、有自己的属性。
- **地图**：俯视 2D，大约几百米见方。后期作品加入了地形高度，以及**多层建筑**（可以看到建筑的侧面）。
- **部署阶段**：地图分成三块：敌占区（深灰）、无人区（浅灰）、己方区（不着色）。玩家把小组拖到己方区。坦克不能放进建筑，步兵不能放进河里。

## 3. 指令系统 ✅

CC1 只有 **6 个指令**，步兵和载具共用：

| 指令 | 效果 |
|---|---|
| Move（移动） | 正常速度移动，边走边观察 |
| Move Fast（快速移动） | 更快，但更累、警觉性更低、还击能力更差 |
| Fire（开火） | 直射武器需要视线；迫击炮是间接火力，不需要视线 |
| Smoke（烟雾） | 持续约 1 分钟，烟柱的宽度和高度差不多，默认风向西→东 |
| Defend（防御） | 用一个蓝色扇形设定警戒弧。美军看到敌人就开火，德军等敌人进入伏击位置再开火。扇形越宽，队形越散 |
| Hide（隐蔽） | 躲进最近的掩体，只对 30 米内的敌人开火 |

另外还有**全军指令**：全体推进（Move Out）、全体防御（Defend）、全体后撤（Pull Back）、结束战斗（End Battle）。
💭 后续作品又加入了潜行（Sneak）、伏击（Ambush）等指令。

**关键的交互细节：**
- 指令文字的颜色表示执行情况：**绿**=正在执行你的命令；**红**=因为战场情况在**违抗**你的命令；**白**=没有命令或已经完成（自动进入防御，自己找目标）。
- 小组有一个 **8 方向威胁玫瑰图**，遭到哪个方向的射击，那个方向就变红。
- 小组会自动在扫描弧内找最近的掩体，受到威胁时会自己换掩体。

## 4. 士兵心理模型：这个系列的灵魂 ✅

开发者请了战斗创伤专家 Steven Silver 博士做顾问。每个士兵有一个"焦虑指数"，由疲劳、准备程度、战斗经验、过往战果等因素决定，再换算成行为概率表。CC1 光心理模型的代码就有约 2000 行，AI 占用的 CPU 比画面还多。

**6 项能力值（连续数值）**

| 能力 | 影响 |
|---|---|
| Physical（体格） | 抗伤、抗疲劳 |
| Mental（心智） | 被伏击时的反应速度，排除卡壳和维修，从战斗中学习的速度 |
| Leadership（领导力） | 小队凝聚力，降低队伍崩溃逃跑的概率 |
| Morale（士气） | 不容易被压制或陷入恐慌 |
| Experience（经验） | 会不会找掩体、选武器、选弹种，受伤概率更低 |
| Skill（技能） | 命中率 |

**状态**

- 健康：健康 → 轻伤（能力下降）→ 重伤失能（无法接受命令）→ 阵亡。
- 情绪：狂暴 / 狂热 / 英勇 / **稳定（默认）** / 恐慌（需要重整）/ 溃逃（逃离战场）。
- 疲劳：充沛 → 气喘（很快恢复）→ 疲惫（表现下降）。奔跑、背重武器、长时间交火都会累积疲劳。
- 当前行动（共 30 多种）：其中最关键的是**被压制**（躲着但还会还击）→ **被钉住**（躲得多、打得少）→ **畏缩**（几乎不开火，拒绝移动）→ **恐慌**（跑去找看不见敌人的地方）→ **溃逃**。

**压力来源**：遭炮击、被伏击、兵力劣势、被坦克攻击、被包围、暴露在开阔地。
**减压来源**：兵力优势、成功伏击敌人。
**情绪变化**：好的领导、队伍打出战果、没有被压制，情绪会上升；差的领导、身边有人伤亡、持续被压制，情绪会下降。

**指挥层级**：连长（玩家本人）→ 排长（4 个以上小组）→ 班长（2–4 个小组）→ 组长 → 副手。领导倒下由下一级接替。领导的质量影响周围小组的心理状态。

**带来的玩法效果**：
- 莽冲没有用，部队会自己找掩体、拒绝命令，甚至开小差。
- 补充兵和预备队动作更慢、更容易恐慌。
- 危险的命令（比如离开掩体冲过开阔地）经常被拒绝执行。

## 5. 视线与战争迷雾 ✅

- **视线工具**：拖出一条瞄准线。**红**=可见也可射击；**暗红**=能打到但看不见；**变黑**=从变黑的那一点开始被挡住。
- **观察等级**：隐藏（不显示在地图上）/ 隐约（在阴影里）/ 被发现（显示在地图上，更容易遭到射击）。
- **只能看到自己士兵看见的敌人**。CC3 有选项可以关闭战争迷雾。
- **火力图**：每个小组在 20 / 40 / 80 / 160 / 320 / 640 米六个距离档上的火力强弱。反坦克一栏显示橙色，表示要打侧面或后面才能击毁重装甲。

## 6. 胜利条件与战斗结束 ✅🔶

- **胜利点（Victory Location，VL）**：地图上插旗的建筑或地点。争夺中的 VL 显示半面旗。
- **全军士气（Force Morale）**：整支部队的平均士气，显示为一条士气条。己方变红而敌方还是黄或绿，就判负（部队放弃战场）。
- **结束方式**：
  1. 时间耗尽，按占领的 VL 和造成的伤亡计算胜负；
  2. 一方士气崩溃；
  3. 一方主动结束（认输，至少判小败）；
  4. 🔶 CC2：双方都点"停火"才结束。凝聚力低于 30%，或者双方都低于 50%，战斗自动结束。
  5. 🔶 后期作品：士气崩溃时，胜方额外获得 VL（Panthers in the Fog 中，士气领先 66% 以上可多得 3 个 VL）。
- **CC1 计分**：击杀士兵、轻型车辆、火炮、重型车辆分别算分，美德双方分值不同。VL 按重要性分为 1–19、20–39、40–100 分。打下来并守到最后得全分；开局就在手里的只得一半；争夺中的双方平分。
- **胜负等级**：大胜 / 中胜 / 小胜，以及对应的三种败。

## 7. 载具 ✅💭

- 状态：正常 → 受损（乘员受伤、武器损坏或减速）→ 瘫痪（不能移动）→ 弃车 → 起火 → 殉爆 → 烧毁。
- 分部件状态：主炮、车首机枪、同轴机枪、行动能力、防空机枪。
- 弹种：AP 穿甲弹、HE 高爆弹、HEAT 破甲弹、烟雾弹、SP 特种弹（霰弹、高速穿甲弹）。
- 💭 后期作品对装甲按正面、侧面、后面分别计算，考虑命中角度和装甲厚度。乘员会弃车，弃车的乘员变成步兵小组。

## 8. 战役层的演进 ✅🔶

| 作品 | 战役形式 |
|---|---|
| CC1 | **线性战役 + 按胜负等级分支**：美军大胜跳两关、中胜跳一关、小胜进下一关、失败重打、惨败退一关（德军反过来）。目标是 43 天内拿下圣洛。不能购买兵力，只能使用预设兵力，阵亡的由补充兵替换 |
| CC2 | 按行动推进，行动内部可以双方停火 1–7 小时休整 🔶 |
| CC3 | 1941–45 大战役，可选任一方；**同一批士兵贯穿四年**；用征用点数挑选和补充兵力 |
| CC4 / CC5 | **战略地图**：40 多个区域，每个区域最多一个"战斗群"（10–15 个单位，代表一个师）。战斗群相遇就开打。补给沿交通线走，十字路口是战略要点。补充兵力是预设的，不能自由购买 🔶 |
| 后期重制作品 | 大战役 + 战略地图 + 战斗群 + 场外支援（炮兵、空袭） |

**跨战斗的持续性**（CC1 已有）：
- 经验**只增不减**，靠活下来积累，心智高的士兵涨得快。
- 领导力每战之后可能升，也可能降。
- 精英小组被补入新兵后，整体质量会下降。
- 勋章：美军（荣誉勋章、银星……紫心）/ 德军（骑士铁十字、金质德意志十字、一级 / 二级铁十字、突击章、战伤章）。
- 小组质量用 1–4 条金杠表示（由平均经验和基础士气决定）。

## 9. 口碑：被夸的和被骂的 ✅

**被夸的**：
- "兵棋向前迈了一大步"。心理模型带来前所未有的真实感。
- CC3 是系列评价最高的一作：GameSpot 9.2、IGN 9、PC Gamer US 92%，获得 1999 年最佳兵棋。

**被骂的**：
- **不听指挥让人觉得"挫败、不公平"**（Next Generation）。玩家不知道士兵为什么不听。
- **可读性差**：美军士兵看起来像灌木丛。屏幕信息太多，太乱。
- 卷屏卡顿。💭 玩家社区长期抱怨寻路差（坦克卡在建筑上，小组走散）。
- 题材面窄，深度有限（部分评测的观点）。

## 10. 对 Close Fight 的启示（初步想法，待讨论）

**必须保留的灵魂**
1. 有名有姓的士兵，加上心理模型（压制 → 钉住 → 恐慌 → 溃逃）。
2. 视线工具和真正的战争迷雾。
3. 用胜利点加全军士气决定胜负，而不是全歼敌人。
4. 士兵跨战斗成长，让玩家心疼伤亡。

**可以做得比原作更好的地方**
1. **让"不听话"变得可理解**：士兵违抗命令时显示原因（"被机枪压制""排长阵亡""弹药耗尽"）。原作被骂主要就是因为玩家看不到原因。
2. **可读性**：现代 UI，敌我识别清晰，状态一目了然。
3. **寻路和编队**：用现代寻路算法，小组保持队形，载具更聪明。
4. **城市竖向空间**：斯大林格勒的特点就是逐层、逐房间争夺（详见 stalingrad-background.md）。CC 原作对多层建筑的表现比较浅，这里可能就是我们的差异化卖点。
