# 班组栏的单位图（M18）

班组栏里每个班组和排的小格，放的是一张**彩色的渲染群像**，参照后期 Close Combat 的做法：

- 每种单位、每一方各一张，同类单位共用。比如所有德军步兵班都用同一张。
- 步兵班组用 CC 的**近景取景**：
  - 二到四个人肩并肩，每人做自己的事（班长举望远镜、机枪手扛着机枪、副射手提弹药箱）；
  - 钢盔几乎贴着上沿，腿在膝盖附近被下沿切掉，人占满格子。
- 车和炮画整体，炮连同炮手。
- 实际剩几个人、伤情如何，看名字旁边的人头标记。

2026-11-24 定下这个方向，之前的纯黑剪影方案作废：用户不要剪影，也不要黑白；后来又指出四个人动作一样太呆板。2026-11-26 用户指出图没有填满格子、不像 CC，于是改成上面的近景取景。

## 本机模型出图（已停用，留作记录）

2026-11-24～26 步兵班组用本机的 Draw Things 出过一版。2026-11-27 起停用：模型由用户在 Draw Things 里删掉，候选图（`ArtSource/roster/candidates/`）已移进废纸篓。要重新用这条路，得先在 Draw Things 里重新下载 Z Image Turbo。


- **工具**：Draw Things（Mac App Store 免费）。
- **模型**：Z Image Turbo 1.0，Apache 2.0 许可，可以商用。约 30 秒一张。
- 2026-11-25～26 比较过另外两个模型，用户都觉得不如 Turbo：
  - Qwen Image 2512：人脸雷同，常画坏枪（少枪管），约 10 分钟一张。
  - Z Image Base（未蒸馏版）：约 3 分钟一张，画面更自然，但用户觉得不如 Turbo。
- Turbo 不理会反向提示词，所以要避免的东西都写进正向提示词：
  - 写明 1942 年的具体武器（Kar98k、直弹匣 MP40、MG34；莫辛步枪、带圆弹鼓的 PPSh、顶上有弹盘的 DP），否则会画出 AK 式的弯弹匣；
  - 写明不要任何徽章、勋章、胸鹰。
- 每种单位出 8 张候选，Claude 先筛掉穿帮的、有标志的、画坏的，每种留 2 张做成总表（原图和小格里的样子并排），用户挑。

### 准备

Draw Things 打开着，设置 → Advanced → API Server：

- 打开；
- 协议 HTTP，端口 7860；
- IP 建议选 localhost。

Claude 通过这个接口出图，**用户不用在界面里操作，也不用切换模型**。

### 步骤

1. **出候选图**：提示词都在 `tools/roster/units.json`，一个单位一条，逐个写明前排每个人的动作和武器。
   ```bash
   python3 tools/roster/generate.py --model zimage --keys unit_de_rifle,unit_su_rifle --seeds 8 --seed 5001
   ```
   - 候选图存进 `ArtSource/roster/candidates/<单位>/`，git 不管这个目录。
   - 每张图旁边有一个同名 `.json`，记下完整的请求，以后可以原样重出。
2. **挑图、处理**：每个单位挑一张最好的。
   ```bash
   python3 tools/roster/process.py ArtSource/roster/candidates/unit_de_rifle/zimage_5003.png …
   ```
   Codex 交来的车和炮图（`ArtSource/codex/roster/unit_<单位>.png`，透明底）也用同一个命令处理：单位名从文件名取，透明底直接保留。
   处理时会：
   - 去掉白底（包括腿和胳膊之间的白缝）；
   - 模型常在脚下画一片浅灰的地面投影，处理时把它变成很淡的半透明暗影，不会在小格里留下一片白（浓淡由 `process.py` 里的 `SHADOW` 控制）；
   - 裁掉空白；
   - 补成小格的比例（76 × 54），人站在底边；
   - 存成 4 倍大小的 `Assets/CloseFight/Resources/Art/Roster/<单位>.png`；
   - 原图如果不在 `ArtSource/` 里（本机候选图），另存一份到 `ArtSource/roster/<单位>.png`；Codex 的原图本来就在 `ArtSource/codex/`，不再重复保存。
3. **检查**：`ArtSource/roster/preview.png` 里有每张图放在小格里的实际大小和放大 3 倍的样子。

返工某一张：在 `units.json` 里改它的提示词，换几个种子重出，再挑一次。

**排的小格**：

- 先找 `platoon_<de|su>_<类型>.png`；
- 没有就用排里第一个班组的图，比如 1 排就用它第一个步兵班的图。

所以排的专门图片可以以后再补。

## 规矩

- 不要任何标志：卐字、鹰徽、红星、十字、编号、标语都不要。提示词里已经写了。出来的图如果有，就不选它。
- 人物三分之四正面，白底，不要地面和投影，方便抠图。
- 小格背景沿用橄榄色。2026-11-24 对比过深灰色，德军的原野灰在橄榄色上更清楚。
